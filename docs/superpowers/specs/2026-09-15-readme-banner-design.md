# BenchWeave SDK README banner design

## Purpose

Create a wide README hero graphic that identifies the repository as the BenchWeave plugin developer SDK while remaining visibly part of the main BenchWeave project family.

## Approved direction

Use a sibling-banner design derived from the main project's visual language: a dark navy technical grid, polished 3D instrumentation, cyan and amber connection lighting, strong white title typography and a restrained pale-blue subtitle.

The banner text is:

- Title: `BenchWeave SDK`
- Tagline: `Build. Validate. Integrate.`

## Composition

Use a wide landscape composition suitable for the top of a GitHub README. Keep the title and tagline on the left with generous clear space and high contrast. Place the technical scene on the right.

The technical scene should show a developer plugin package moving through three legible conceptual stages:

1. Build — a modular plugin/package object.
2. Validate — descriptor, tests or verification cues.
3. Integrate — a connection into the BenchWeave gateway and representative bench instruments.

Use visual cues rather than dense interface text. Connections should read left-to-right or centre-out and retain the main banner's cyan/amber split.

## Constraints

- Match the main project banner's family resemblance without duplicating its exact scene.
- Spell all visible text exactly.
- Keep the visual professional, technical and credible rather than playful.
- Avoid third-party logos, watermarks, tiny illegible labels and unsafe laboratory imagery.
- Preserve strong readability when rendered at typical GitHub README width.
- Save the final project asset under `docs/assets/` using a descriptive PNG filename.
- Add descriptive alt text and place the image at the top of `README.md`.

## Verification

Before integration, inspect the generated image for title and tagline accuracy, composition, project-family consistency, and readability. After integration, verify the asset exists at the referenced path and the Markdown link resolves.
